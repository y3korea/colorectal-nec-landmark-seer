# Output map: script → result file → manuscript item

Paths are relative to the repository root with default settings (`results/` = `NEC_RESULTS_DIR`, `figures/output/` = `NEC_FIG_DIR`).
"Table S" = Supplementary Table, "Fig. S" = Supplementary Figure (International Journal of Cancer submission, v3).
Every JSON listed here has a reference copy in `reference_results/` that `tests/compare_with_reference.py` checks. The reference copies are publication-safe: `tools/suppress_small_cells.py` replaced the cells based on 1–4 patients (SEER DUA item 14) by `"suppressed (SEER small-cell rule)"` in `A04.json` (per-code table: all characteristics, including stage, of the codes with 1–4 patients; % male of code 8241, whose share implies 1–4 men or women, and complementarily of code 8045), `A08.json` (raw race/ethnicity counts; landmark-6 hazard ratio of the race/ethnicity level "Other", 1–4 patients at risk), `A10.json` (information on individual patients withheld as in Supplementary Tables S5, S34, S35 and S37: survival-day minimum/maximum, maximum days to treatment, single-patient categories that the Supplement pools, with their pooled partners; the later-primary rows of the sequence × stage table outside the distant column; multiple-primary sequence of the patients shared between two cohorts) and `figure_data.json` (lung-export age step) — 92 fields in all; the comparison skips those fields. The pooled hazard grid `results/A09_hazard_grid.csv` (0.25-month grid with pointwise bootstrap bands; Supplementary Table S33, Figure 2B, Supplementary Figure S5) is regenerated by `R/A09_smoothed_hazards_muhaz.R` and is not stored in the repository; its monthly values are in `reference_results/A09.json`.
